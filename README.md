# AtlasCore Hub

A multi-device linked development ecosystem built for productivity, organization, and scalable project management.

## Overview

AtlasCore Hub is the central workspace for all AtlasCore development projects. It is designed to support synchronized workflows across connected devices and maintain a clean, modular repository structure.

## Structure

```
AtlasCore_Hub/
├── .github/
│   └── agents/

├── MD/
├── PIX/
├── .gitignore

```

## Branch

- Default branch: `Dev`

## Getting Started

1. Clone the repository
2. Open in VS Code
3. Use the **AtlasCore Dev** agent for development assistance
